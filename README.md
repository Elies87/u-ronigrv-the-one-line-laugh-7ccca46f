# The One-Line Laugh

[![make.fun](https://make.fun/badge/u-ronigrv-the-one-line-laugh-7ccca46f.svg)](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f)

## Entry

> My smartwatch congratulated me for standing up — the saddest applause I've ever received.

(89 characters — one sentence, well under the 200-character limit.)

## How it works

`entry/main.py` is a small deterministic Python program. It writes the
one-line joke above to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`). No input, no network, no randomness — running it twice
produces byte-identical output.
